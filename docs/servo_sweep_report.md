# Visual servo robustness sweep (simulation)

Generated by `rosrun arm_servo servo_sweep --out sweep.csv --report servo_sweep_report.md` on 2026-10-08 (about one minute on 20 cores).

384 closed-loop runs with the real arm kinematics (`servo_sim.h`), 40 s each, 10 Hz camera. Every run starts from a random marker position (lateral +-8 cm, 22 to 38 cm ahead) and a random camera-mount error of up to 10 deg and 10 mm (the controller believes the wrong mount). A run PASSES when the supervisor declares DONE (|e| < 5 mm and pitch < 0.05 rad for 1 s) with no abort, no base collision, never closer than 8 cm to the marker, joint speed within the 0.3 rad/s cap, and a final true error within the mount-error bound (5 mm + 2 sin(rotation error / 2) x 16.2 cm + translation error + 4 mm; see servo_law.h).

## Result

Largest gain tested that passed every run with a camera delay up to 0.3 s, all arm lags and the realistic noise levels (0 and 1 mm): **lambda = 2.00 1/s** (the shipped default is 1.0). A margin of at least a factor 2 below the largest passing gain is sensible; the grid is coarse (0.5, 1, 2, 3, 5), so read it as a bracket, not a measurement.
